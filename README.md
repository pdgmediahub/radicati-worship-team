# RADICATI · Worship Team — Black & White

Scaletta ufficiale: 9 brani, 3 sessioni, in ordine. I PDF originali sono nella cartella `pdf/`, visualizzabili direttamente nella scheda di ciascun brano, oppure apribili in una nuova scheda.

## Pubblicazione / aggiornamento GitHub Pages
Caricare `index.html`, `repertoire.js`, `.nojekyll`, le cartelle `pdf/` e `audio/` nella **radice** del repository (non caricare lo ZIP come unico file). In GitHub Settings → Pages, source `Deploy from a branch`, branch `main`, folder `/(root)`.

## Audio
Quando disponibili, inserire MP3 nella cartella `audio/`, poi impostare il campo `audio` del brano in `repertoire.js`, per esempio `audio/01-jehovah-nissi.mp3`.

## Importante
La password condivisa lato browser serve solo come filtro di navigazione: **non è sicurezza reale**. Tutti i PDF caricati su GitHub Pages e nel repository pubblico sono accessibili direttamente. Non caricare documenti riservati. Le funzionalità di trasposizione si applicano solo ai brani con chart strutturati, non ai PDF originali.
